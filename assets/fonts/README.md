# Mahy Mythic Labs — Font Library

## Purpose

This folder stores approved font files and font-related documentation used in Mahy Mythic Labs branding, thumbnails, titles, captions, lower thirds, banners, and publishing assets.

## Font Usage Principle

Typography should feel cinematic, intelligent, timeless, and highly legible.

Use fonts to support the story—not to make the design feel decorative, futuristic, or overly complex.

## Font Categories

| Category | Primary Use |
| --- | --- |
| Display font | Episode titles, thumbnails, banners, major headings |
| Body font | Descriptions, documents, long-form text |
| Subtitle font | Video captions and subtitles |
| UI / utility font | Lower thirds, labels, dates, locations, metadata |

## Usage Rules

- Use only fonts with verified commercial-use rights.
- Record every third-party font in `assets/licenses/asset_license_tracker.md`.
- Keep original font files and license documents together where possible.
- Do not use fonts from unknown or unverified sources.
- Do not stretch, distort, outline excessively, or apply unreadable effects to type.
- Use no more than two font families in a single episode package unless a documented exception is approved.
- Maintain consistent typography across thumbnails, titles, lower thirds, captions, and social assets.

## Readability Rules

- Prioritize legibility on mobile screens.
- Use sufficient contrast between text and background.
- Avoid thin weights over busy imagery.
- Use large, bold type for thumbnails and short-form titles.
- Keep caption type simple and easy to read.
- Avoid long all-caps text blocks.
