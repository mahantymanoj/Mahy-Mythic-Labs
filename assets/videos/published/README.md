# Final Videos

## Purpose

This folder contains final-approved, publish-ready video masters and approved delivery versions.

## Allowed Content

- Final 16:9 YouTube masters
- Final 9:16 Shorts masters
- Captioned delivery versions
- Platform-specific exports
- High-quality archival masters

## File Naming

Use:

`[episode-or-project]-[format]-final-v##.[extension]`

Examples:

`ep001-16x9-final-v01.mp4`

`ep001-9x16-short-final-v01.mp4`

`ep001-16x9-final-captions-v01.mp4`

## Final Approval Requirements

- [ ] Script and narration are factually verified.
- [ ] Visuals match the approved storyboard.
- [ ] No AI artifacts, anachronisms, or continuity issues remain.
- [ ] All music, SFX, images, and clips have documented rights status.
- [ ] Audio is clear and balanced.
- [ ] Captions are accurate where included.
- [ ] Thumbnail, title, and description match the final story.
- [ ] Final export plays correctly from start to finish.
- [ ] Final file is recorded in the episode asset manifest.

## Rules

- Never overwrite a final master.
- Create a new numbered version for revisions.
- Preserve the highest-quality master alongside platform delivery files.
- Treat this folder as publish-ready and read-only after approval.
