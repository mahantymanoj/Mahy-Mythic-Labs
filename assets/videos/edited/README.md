# Edited Videos

## Purpose

This folder contains approved working edits, assembled scene sequences, color-corrected clips, and review exports.

## Allowed Content

- Scene assemblies
- Rough cuts
- Fine cuts
- Color-corrected clips
- Sound-synced edits
- Internal review exports
- Captioned review versions

## File Naming

Use:

`[episode-or-project]-[edit-type]-v##.[extension]`

Examples:

`ep001-rough-cut-v01.mp4`

`ep001-scene03-edit-v02.mp4`

`ep001-review-export-v01.mp4`

## Rules

- Maintain version numbers for every meaningful edit.
- Keep generated source clips traceable through the episode asset manifest.
- Review edits for pacing, continuity, factual clarity, audio balance, and visual artifacts.
- Do not label a file as final until all quality checks are complete.
- Keep review exports separate from the final master.
