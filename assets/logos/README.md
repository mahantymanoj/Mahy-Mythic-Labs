# Mahy Mythic Labs — Logo Library

## Purpose

This folder contains the official Mahy Mythic Labs logo files, wordmarks, icon marks, watermark exports, and approved logo variations.

All logo use must follow:

`assets/branding/logo_guidelines.md`

## Logo Asset Types

| Asset Type | Purpose |
| --- | --- |
| Primary logo | Main brand identity for banners, end cards, and official documents |
| Wordmark | Text-based Mahy Mythic Labs identity |
| Icon mark | Profile images, watermarks, favicons, and small placements |
| Light variant | Use on dark backgrounds |
| Dark variant | Use on light backgrounds |
| Monochrome variant | Use where color is unavailable or distracting |
| Transparent export | Use in video overlays and flexible compositions |
| Social avatar | Use for YouTube and social profile images |

## File Naming

Use:

`brand-mahy-[logo-type]-[variant]-v##.[extension]`

Examples:

```text
brand-mahy-primary-light-v01.svg
brand-mahy-wordmark-dark-v01.png
brand-mahy-icon-monochrome-v01.svg
brand-mahy-watermark-light-v01.png
```

| Format | Use |
| --- | --- |

## Storage Rules

- Keep vector master files in SVG format whenever possible.
- Keep transparent PNG exports for video and thumbnail use.
- Do not store unapproved logo concepts with approved assets.
- Keep old versions only when they are labeled as archived or superseded.
- Never overwrite an approved logo master; create a new version.

## Usage Rules

- Use only approved logo files from this folder.
- Maintain the original proportions and clear space.
- Use the light logo on dark backgrounds and the dark logo on light backgrounds.
- Do not recolor, rotate, stretch, crop, or add decorative effects to the logo.
- Do not place a logo over a busy or low-contrast image.
- Use the icon mark when the full wordmark is too small to read.
- Follow the watermark placement rules in `assets/branding/logo_guidelines.md`.
