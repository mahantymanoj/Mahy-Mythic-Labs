# Narration Assets

## Purpose

This folder stores recorded, generated, edited, and approved narration for Mahy Mythic Labs productions.

## Allowed Content

- Raw voice recordings
- AI voice outputs
- Cleaned narration takes
- Final narration masters
- Alternate line reads
- Pronunciation notes
- Script-to-audio timing references

## File Naming

Use:

`[episode-or-project]-[narration-type]-[language]-v##.[extension]`

Examples:

`ep001-narration-en-v01.wav`

`ep001-narration-clean-v02.wav`

`ep001-narration-final-v01.wav`

## Required Metadata

Each narration asset must record:

- Episode or project ID
- Script version
- Voice source or narrator
- Language and accent
- Recording or generation date
- Editing status
- Rights or usage status
- Final approval status

## Quality Requirements

- Clear speech on headphones and phone speakers
- Consistent volume and tone
- No clipped words, harsh breaths, or distracting noise
- Accurate pronunciation of names, places, and technical terms
- Timing aligned with the approved script

## Rules

- Do not use a voice that imitates a real person without permission.
- Keep raw recordings separate from cleaned and final versions.
- Never overwrite a final narration master.
- Record the narration version used in the episode asset manifest.
