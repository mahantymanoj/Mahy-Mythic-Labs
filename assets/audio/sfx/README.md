# Sound Effects Assets

## Purpose

This folder stores original, licensed, and approved sound effects for Mahy Mythic Labs productions.

## Allowed Content

- Environmental ambience
- Foley
- Transitions
- Mechanical sounds
- Water, wind, fire, and nature sounds
- Cinematic impacts
- Atmospheric textures
- Designed effects for science, history, and cosmic sequences

## File Naming

Use:

`[category]-[sound]-[variation]-v##.[extension]`

Examples:

`sfx-bronze-gear-turn-01-v01.wav`

`sfx-aegean-storm-distant-01-v01.wav`

`sfx-cosmic-low-rumble-02-v01.wav`

## Required Metadata

Each SFX asset must record:

- Asset ID
- Sound description
- Source or creator
- License type
- Commercial-use status
- Attribution requirement
- Duration
- Category
- Intended use
- Approval status

## Quality Requirements

- Clean audio with no unwanted clipping or noise
- Appropriate realism for historical and natural environments
- No distracting or exaggerated effects
- Sound must support the story, not call attention to itself
- Volume must remain below narration unless intentionally featured

## Rules

- Use only original or commercially licensed sound effects.
- Store proof of license in `assets/licenses/`.
- Avoid cliché effects unless used intentionally.
- Do not use sounds that misrepresent historical, scientific, or natural events.
- Record SFX placement in the episode cue sheet and asset manifest.
