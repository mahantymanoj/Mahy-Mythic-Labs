# Mahy Mythic Labs — Sound Effects Library

## Purpose

This folder contains reusable, approved sound effects for Mahy Mythic Labs productions.

Episode-specific SFX edits, mixes, and cue sheets belong in:

`projects/EP###/audio/sfx/`

## Sound Effect Categories

| Category | Purpose |
| --- | --- |
| Atmosphere | Wind, rain, ocean, forest, city, desert, space ambience |
| Foley | Footsteps, cloth, objects, tools, writing, handling artifacts |
| Mechanical | Gears, machinery, mechanisms, doors, instruments |
| Nature | Thunder, water, fire, birds, insects, environmental movement |
| Cinematic | Impacts, risers, drones, transitions, pulses |
| Historical | Ships, markets, workshops, weapons, ancient tools |
| Cosmic | Low rumbles, stellar textures, abstract space sound design |
| Interface | Minimal UI sounds for future technology or data visualization |

## File Naming

Use:

`sfx-[category]-[sound-name]-[variation]-v##.[extension]`

Examples:

```text
sfx-mechanical-bronze-gear-turn-01-v01.wav
sfx-atmosphere-aegean-storm-distant-01-v01.wav
sfx-cosmic-low-rumble-02-v01.wav

## Required Metadata

Every sound effect must record:

- SFX ID
- Sound name and description
- Category
- Duration
- Source or creator
- License ID
- Commercial-use status
- Attribution requirements
- Modification permission
- Intended narrative use
- Approval status

## Sound Design Direction

Sound effects should feel:

- Cinematic
- Immersive
- Physically believable
- Subtle and intentional
- Supportive of the narration and visual story
- Appropriate to the historical, scientific, mythological, or cosmic setting

Avoid exaggerated trailer impacts, repetitive whooshes, cartoon-like effects, and sounds that distract from the story.

## Usage Rules

- Use only original or commercially licensed sound effects.
- Record every third-party sound in `assets/licenses/asset_license_tracker.md`.
- Do not use copyrighted audio from films, television, games, social platforms, or other videos without permission.
- Keep raw source files, license documents, and edited versions.
- Do not overwrite approved SFX; create a new version for edits.
- Record each SFX use and timestamp in the relevant episode cue sheet.
- Keep reusable library SFX separate from episode-specific mixes.

## Approval Checklist

- [ ] Source and license are verified.
- [ ] Commercial use is permitted.
- [ ] Attribution requirements are documented.
- [ ] Audio is clean and free from unwanted noise or clipping.
- [ ] Sound is appropriate to the scene and setting.
- [ ] SFX does not overpower narration or music.
- [ ] Asset is added to `assets/asset_database.md`.
- [ ] License details are recorded in `assets/licenses/asset_license_tracker.md`.
