# Mahy Mythic Labs — Logo Guidelines

## Logo Role

The Mahy Mythic Labs logo represents a meeting point between ancient knowledge, human curiosity, and cosmic exploration.

It should feel refined, timeless, and cinematic—not corporate, playful, or overly ornamental.

## File Storage Location

All official logo files are stored in:

`assets/logos/`

Do not save logo files to any other location. Reference `assets/logos/README.md` for format requirements and the logo register.

## Approved Logo Variants

| Variant | Use |
| --- | --- |
| Primary light logo | Dark video frames, dark banners, dark thumbnails |
| Primary dark logo | Light documents and bright visual backgrounds |
| Monochrome logo | Watermarks, subtle overlays, limited-color applications |
| Icon / mark | Profile images, favicons, social avatars, small placements |

## Clear Space

Maintain clear space around the logo equal to at least the height of the logo's primary letterform.

Do not place text, faces, complex objects, or high-contrast edges within this area.

## Minimum Size

| Placement | Minimum size |
| --- | --- |
| Video watermark | 80 px wide |
| Thumbnail | 140 px wide |
| YouTube banner | 220 px wide |
| End card | 260 px wide |

If the logo is not clear at the intended size, use the icon mark or remove it.

## Background Use

- Use the light logo on dark, low-detail backgrounds.
- Use the dark logo on bright, low-detail backgrounds.
- Add a subtle dark overlay behind the logo if necessary for readability.
- Never place the logo directly over a busy focal subject.

## Prohibited Uses

Do not:

- Stretch, compress, skew, or rotate the logo
- Change its approved colors. The approved color palette is defined in `production_bible/COLOR_PALETTE.md`. Any recoloring outside those defined values is prohibited.
- Add glow, bevel, 3D extrusion, or heavy shadows
- Place it over unreadable or overly detailed imagery
- Combine it with unrelated logos or symbols
- Use it as decorative texture

## Watermark Use

For video watermark placement:

- Position: bottom-right
- Opacity: subtle but legible
- Margin: consistent title-safe spacing
- Duration: after the opening hook, unless editorially required earlier

The watermark must support recognition without distracting from the story.

## Approval Checklist

- [ ] Logo is consistent with Mahy Mythic Labs brand identity.
- [ ] Logo is readable at small and large sizes.
- [ ] Light, dark, and transparent variants are available.

- [ ] Video watermark export is available.

- [ ] Logo follows the approved color palette.
