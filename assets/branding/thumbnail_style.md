# Mahy Mythic Labs — Thumbnail Style Guide

## Purpose

A thumbnail must create immediate curiosity while accurately representing the episode's central question.

It is a cinematic promise, not a summary of the video.

## Dimensions

| Specification | Value |
| --- | --- |
| Standard size | 1280 × 720 px |
| Maximum file size | 2 MB (YouTube requirement) |
| Aspect ratio | 16:9 |

## File Naming

Use:

`[episode-or-project]-thumbnail-[variant]-v##.[extension]`

Examples:

`ep001-thumbnail-main-v01.jpg`

`ep001-thumbnail-shorts-v01.jpg`

## Visual Formula

Each thumbnail should contain:

1. One dominant subject
2. One clear mystery or contradiction
3. Strong light-versus-dark separation
4. Minimal text, if any
5. A sense of scale, age, discovery, or cosmic consequence

## Composition

- Use one primary focal object, face, monument, artifact, or celestial event.
- Keep the subject large enough to read on mobile.
- Use depth: foreground subject, atmospheric middle ground, simplified background.
- Preserve negative space for optional text.
- Avoid clutter, collages, tiny details, and multiple competing focal points.

## Color and Lighting

- Favor cinematic contrast.
- Use deep blacks, aged bronze, stone, indigo, teal, gold, and restrained cosmic color.
- Use warm light for discovery and human history.
- Use cool darkness for mystery, depth, water, night, and space.
- Avoid oversaturation and generic neon AI aesthetics.

## Typography

- Use no more than three words. Fewer words force clarity and ensure the thumbnail reads instantly at small sizes on mobile feeds, where a viewer has less than a second to decide.
- Text must be readable on a mobile screen.
- Use text only when it increases curiosity or clarity.
- Avoid explanatory sentences, excessive punctuation, and clickbait phrases.

## Thumbnail Text Examples

Good:

- LOST KNOWLEDGE
- BEFORE HISTORY
- THE FIRST STAR
- ANCIENT MACHINE

Avoid:

- YOU WON'T BELIEVE THIS
- SHOCKING TRUTH
- THEY HID THIS
- PROOF OF ALIENS
- THE TRUTH THEY DON'T WANT YOU TO KNOW
- EVERYTHING YOU KNOW IS WRONG

## Episode-Type Directions

| Episode type | Thumbnail focus |
| --- | --- |
| Ancient mystery | Artifact or monument against darkness |
| Mythology | Iconic symbolic image with emotional scale |
| Cosmos | One celestial event or object at immense scale |
| Human evolution | Human silhouette, ancient landscape, or pivotal tool |
| AI future | Human-machine contrast with restrained visual language |

## Approval Checklist

- [ ] The subject is obvious at small size.
- [ ] The image creates a single strong question.
- [ ] The thumbnail does not misrepresent the episode.
- [ ] Text is minimal and readable.
- [ ] No visible AI artifacts, warped objects, or invented text.
- [ ] It feels cinematic, original, and premium.
- [ ] Dimensions are 1280 × 720 px and file size is under 2 MB.
- [ ] File is named according to the naming convention.
