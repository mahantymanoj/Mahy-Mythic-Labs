# Mahy Mythic Labs — Character Registry

## Purpose

This registry tracks every recurring, historical, reconstructed, symbolic, or fictional character used in Mahy Mythic Labs productions.

It protects visual continuity, cultural accuracy, and reuse across episodes.

## Character Categories

| Category | Definition | Example |
| --- | --- | --- |
| Historical | A real documented person | Hypatia, Galileo, an ancient astronomer |
| Reconstructed | Evidence-led portrayal of an unknown historical person | Greek craftsperson, Bronze Age navigator |
| Mythological | A figure from a cultural myth or sacred tradition | Athena, Odin, Vishnu |
| Symbolic | A non-literal visual representation of an idea | Time, Knowledge, Civilization |
| Original | A fictional recurring guide or narrator figure | Future project character |

## Character Rules

- Every recurring character must have a completed metadata file.
- Historical and reconstructed characters must be based on credible research.
- Mythological figures must be portrayed respectfully and never reduced to stereotypes.
- Do not present reconstructed or symbolic characters as documented historical evidence.
- Do not imitate a living person's face, voice, or likeness without permission.
- Maintain consistent age, clothing, features, props, and visual language across scenes.
- Record every approved visual-generation prompt used for recurring characters.

## Status Definitions

| Status | Meaning |
| --- | --- |
| Draft | Concept exists but is not approved for production |
| Approved | Cleared for use and visually consistent |
| Active | Currently used in a live or planned episode |
| Archived | Retained for history; not intended for new use |
| Restricted | Requires cultural, legal, or editorial review before use |

## Naming Convention

Use:

`CHAR-[number]-[short-name]`

Examples:

- `CHAR-001-ancient-astronomer`
- `CHAR-002-athena`
- `CHAR-003-cosmic-narrator`
- `CHAR-004-bronze-age-craftsperson`

## Reuse Guidelines

To reuse an existing character in a new episode:

1. Check this registry to confirm the character is in `Approved` or `Active` status.
2. Open the character's metadata file (listed in the Reference File column).
3. Use the approved visual-generation prompt from the metadata file exactly as recorded.
4. Do not alter appearance, clothing, or key visual features without submitting a new metadata version.
5. Record the new episode use in the metadata file's Related Episodes field.
6. Update this registry's status to `Active` if the character is being used in a new production.

## Approval Checklist

- [ ] Historical or cultural context documented
- [ ] Visual reference and prompt recorded
- [ ] No misleading historical claim
- [ ] No harmful stereotype or sacred misuse
- [ ] Visual continuity reviewed
- [ ] Rights and AI-generation notes recorded
