# Generated Images

## Purpose

This folder contains newly generated AI images that have not yet passed visual, factual, ethical, or rights review.

> **Production rule: Generated does not mean approved. No image in this folder may be used in a final edit or published video.**

## Workflow

1. **Generate** — Place all new AI image outputs in this folder with the correct filename and a linked metadata record.
2. **Review** — Assess each image for visual quality, factual accuracy, ethical appropriateness, and rights status.
3. **Move** — Transfer reviewed images to `../approved/` if they pass, or to `../archive/` if they are rejected or superseded.

## Allowed Content

- Raw AI image outputs
- Prompt-test variations
- Draft keyframes
- Unapproved concept art
- Generation metadata and prompt records

## File Naming

Use:

`[episode-or-project]-[subject]-[shot-or-angle]-v##.[extension]`

Example:

`ep001-antikythera-gear-closeup-v01.png`

## Required Metadata

Every generated image must have a linked or accompanying record containing:

- Episode or project ID
- Prompt used
- Negative prompt used
- Generation tool or model
- Generation date
- Reference assets used
- Creator or operator
- Review status

## Rules

- Generated does not mean approved.
- Do not use files from this folder in final edits or publishing.
- Do not overwrite a generation; create a new version.
- Move approved files to `../approved/`.
- Move rejected or obsolete files to `../archive/`.
