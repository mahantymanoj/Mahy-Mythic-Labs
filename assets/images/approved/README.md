# Approved Images

## Purpose

This folder contains images cleared for production use after quality, continuity, factual, ethical, and rights review.

## Approval Requirements

An image may enter this folder only when:

- [ ] The subject is visually clear and artifact-free.
- [ ] The image supports the approved script and storyboard.
- [ ] Historical, scientific, or cultural details are appropriate.
- [ ] No copyrighted logo, unlicensed likeness, or protected material is visible.
- [ ] The AI-generation prompt and source references are recorded.
- [ ] The image matches Mahy Mythic Labs visual direction.
- [ ] The asset is listed in the relevant asset manifest.

## File Naming

Use:

`[episode-or-project]-[subject]-[shot-or-angle]-approved-v##.[extension]`

Example:

`ep001-antikythera-gear-closeup-approved-v01.png`

## Rules

- Never edit an approved master in place.
- Create a new version if changes are required.
- Keep approved images linked to their original generated version.
- Record every production use in the episode asset manifest.
