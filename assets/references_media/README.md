# Mahy Mythic Labs — Reference Library

## Purpose

This folder stores visual, historical, scientific, cultural, and technical references used to guide research, writing, art direction, and AI generation.

A reference asset is not automatically licensed for use in a published video. References inform the work; they do not substitute for original or properly licensed production assets. This distinction separates `references_media/` from `assets/images/approved/`—images in `approved/` have passed all rights and quality checks and may be used in final production; images here have not.

## Preferred Sources

When sourcing reference material, prefer:

- Museum and institutional archives (e.g., British Museum, Smithsonian, Louvre)
- National and government archives
- Space agencies: NASA, ESA, JAXA
- Wikipedia Commons (verify each file's individual license)
- University libraries and institutional repositories
- Peer-reviewed scientific publications and their accompanying images
- Official cultural heritage bodies and archaeological organizations

## Usage Status

| Status | Meaning |
| --- | --- |
| Research only | May inform the work but cannot be used in final production |
| Licensed | Permission or license has been verified for production use |
| Public domain | Verified public-domain asset; source record still required |
| Original | Created and owned by Mahy Mythic Labs |
| Restricted | Use only under stated limits |
| Pending | Rights or factual status require review |

## File Naming

Use:

`ref-[category]-[subject]-[source-or-year]-v##.[extension]`

Examples:

```text
ref-historical-antikythera-fragment-museum-v01.jpg
ref-scientific-moon-phase-diagram-nasa-v01.png
ref-visual-aegean-storm-lighting-v01.jpg
```

## Required Metadata

Each reference must record:

- Reference ID
- Description
- Source URL, publication, museum, archive, or creator
- Date accessed
- Historical, scientific, or cultural context
- Related episode, character, or environment
- Usage status
- License or attribution information, if applicable
- Notes on accuracy or uncertainty

## Reference Rules

- Treat every downloaded image, video, audio clip, paper, or web page as research-only until rights are verified.
- Do not use a reference image directly in final production unless it is clearly licensed, public domain, or original.
- Always record the original source, even for public-domain material.
- Prefer primary sources: museums, archives, universities, scientific agencies, peer-reviewed research, and official institutions.
- Separate evidence from artistic interpretation.
- Respect cultural and sacred material; do not use it as decoration without context.
- Do not use references that promote misinformation, stereotypes, or unsupported historical claims.

## AI Generation Rules

When a reference is used to guide AI generation:

- Record the reference ID in the generation metadata.
- Use it for factual guidance, composition, material, or atmosphere—not for copying protected artwork.
- Do not request a living artist's exact style.
- Do not use unlicensed reference images as direct image-to-image inputs without permission.
- Review generated output for inaccurate symbols, anachronisms, and misleading depictions.
