# Phase 1 – Foundation & Studio Setup

**Project:** Mahy Mythic Labs Studio OS
**Version:** 1.0
**Status:** In Progress

---

# Objective

The objective of Phase 1 is to establish a strong foundation for Mahy Mythic Labs before producing AI-generated YouTube videos.

This phase focuses on building an organized, documented, and repeatable production environment rather than creating automation.

By the end of this phase, the repository will be ready to support the complete production lifecycle of every YouTube episode.

---

# Philosophy

> **Think like a Creator. Work like an Engineer.**

Our primary goal is to create high-quality AI-generated YouTube videos.

Documentation, Git, templates, prompts, and project organization exist only to support that goal.

We will always prioritize:

* Storytelling
* Authenticity
* Research
* Visual Quality
* Continuous Improvement

Technology is an enabler, not the product.

# Success Criteria

Phase 1 is complete when the following questions can be answered.

* Where should research be stored?
* Where should scripts be written?
* Where should prompts be stored?
* Where should assets be placed?
* How will every episode be organized?
* Can another person understand the repository structure without explanation?

If the answer is yes, Phase 1 is complete.

---

# Folder Responsibilities

## docs/

Contains project documentation.

This folder explains how Mahy Mythic Labs operates.

---

## production_bible/

Contains studio standards.

This is the operating guide for content production.

---

## templates/

Contains reusable templates.

Every new episode should begin by copying these templates.

---

## knowledge_base/

Stores reusable research.

Research completed once should be reusable in future videos.

---

## prompts/

Contains AI prompts categorized by purpose.

Examples include:

* System Prompts
* Image Prompts
* Video Prompts
* Narration Prompts
* Thumbnail Prompts

---

## projects/

Contains all YouTube episode projects.

Each episode is self-contained.

---

## assets/

Stores reusable assets such as:

* Logos
* Fonts
* Music
* Sound Effects
* Branding
* Reference Images

---

## automation/

Reserved for optional helper scripts that save time.

Automation is not a priority during the initial stages.

---

## archive/

Contains completed or deprecated resources that should be preserved for reference.

# Out of Scope

The following items are **not** part of Phase 1.

* AI image generation
* AI video generation
* Voice-over generation
* Video editing
* Thumbnail creation
* YouTube SEO
* Automation development
* Publishing videos
