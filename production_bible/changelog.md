# Version Format

Mahy Mythic Labs follows:

```
Major.Minor.Patch
```

Example:

```
1.0.0
```

Meaning:

```
Major

Large system changes.


Minor

New features or documents.


Patch

Small improvements or corrections.
```

Correction.

