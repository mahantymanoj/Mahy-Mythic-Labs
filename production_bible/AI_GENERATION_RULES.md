# 🤖 AI Generation Rules

> **Mahy Mythic Labs AI Generation Standards**
>
> Version: 1.0
>
> This document defines the mandatory rules, constraints, quality standards, and behavioral guidelines that every AI model, AI agent, workflow, and automation within Mahy Mythic Labs must follow.

---

# 1. Purpose

This document establishes a unified generation standard across all AI providers and models.

Its goals are to ensure:

- Consistency
- Accuracy
- Reliability
- Cinematic quality
- Educational value
- Brand alignment
- Reproducibility

Every AI-generated output should appear as though it was created by a single creative studio.

---

# 2. Scope

These rules apply to every AI component, including:

- Research Agent
- Script Agent
- Storyboard Agent
- Image Agent
- Video Agent
- Narration Agent
- Thumbnail Agent
- SEO Agent
- Quality Agent
- Publishing Agent

They also apply regardless of provider:

- OpenAI
- Anthropic
- Gemini
- Grok
- Local models
- Future providers

---

# 3. Golden Rules

Every generated output must be:

✅ Factually accurate

✅ Educational

✅ Cinematic

✅ Original

✅ Clear

✅ Engaging

✅ Consistent

Quality always takes precedence over speed.

---

# 4. Never Generate

The AI should never generate:

- Fabricated facts presented as truth
- Plagiarized content
- Copyrighted scripts
- Misleading claims
- Hate speech
- Unsafe content
- Clickbait misinformation
- Unsupported historical claims

If uncertainty exists, clearly indicate uncertainty rather than inventing details.

---

# 5. Research Rules

Research should:

- Use multiple reliable sources
- Prefer primary or authoritative references
- Separate facts from theories
- Distinguish hypotheses from established knowledge
- Preserve scientific accuracy

Research should prioritize evidence over speculation.

---

# 6. Script Rules

Scripts should:

- Follow a logical narrative
- Begin with a compelling hook
- Build curiosity
- Maintain factual accuracy
- End with a memorable conclusion

Avoid unnecessary repetition and filler.

---

# 7. Storytelling Rules

Every story should include:

- Curiosity
- Discovery
- Conflict or mystery (where appropriate)
- Resolution
- Reflection

The objective is to educate through storytelling, not sensationalism.

---

# 8. Visual Generation Rules

Generated visuals should be:

- Cinematic
- High detail
- Historically appropriate
- Scientifically plausible
- Consistent with the script
- Consistent with approved character and environment references

Avoid modern objects or styles in historical settings unless intentionally required.

---

# 9. Character Consistency

Recurring characters should maintain:

- Facial features
- Clothing
- Hair
- Age
- Body proportions
- Expressions
- Color palette

Reference assets should be reused whenever available.

---

# 10. Environment Consistency

Locations should remain visually consistent across scenes.

Maintain continuity for:

- Architecture
- Geography
- Lighting
- Time of day
- Weather
- Cultural elements

---

# 11. Video Generation Rules

Generated videos should:

- Match the approved storyboard
- Maintain cinematic pacing
- Use smooth camera motion
- Preserve subject consistency
- Avoid abrupt transitions
- Follow aspect ratio requirements

Every shot should have a clear visual purpose.

---

# 12. Narration Rules

Narration should be:

- Natural
- Calm
- Confident
- Emotionally appropriate
- Easy to understand

Avoid robotic or exaggerated delivery.

The narration should complement the visuals rather than compete with them.

---

# 13. Thumbnail Rules

Thumbnails should:

- Communicate one clear idea
- Be readable on mobile
- Create curiosity without deception
- Match the video's content
- Use approved branding

Avoid excessive text or clutter.

---

# 14. SEO Rules

Metadata should:

- Describe the actual content
- Include relevant keywords naturally
- Avoid keyword stuffing
- Use compelling but truthful titles

SEO should improve discoverability without sacrificing integrity.

---

# 15. Brand Consistency

Every output should align with the Mahy Mythic Labs identity.

Maintain consistency in:

- Tone
- Vocabulary
- Visual style
- Educational focus
- Narrative quality

---

# 16. Prompt Engineering Rules

Prompts should:

- Be explicit
- Provide sufficient context
- Define output expectations
- Specify constraints
- Avoid ambiguity

Prefer structured prompts over conversational prompts for automation.

---

# 17. Multi-Agent Collaboration

Agents should:

- Share structured context
- Avoid duplicating work
- Preserve previous decisions
- Respect outputs from upstream agents

Each agent should focus on its own responsibility.

---

# 18. Error Handling

When an AI model cannot confidently complete a task:

- Report uncertainty
- Explain the limitation
- Request clarification if needed
- Avoid guessing

Confidence should never be simulated.

---

# 19. Copyright Rules

Do not generate:

- Copyrighted scripts
- Protected artwork
- Trademark misuse
- Unlicensed music
- Direct copies of existing creative works

Originality is mandatory.

---

# 20. Hallucination Prevention

Before finalizing an output:

- Check factual consistency
- Verify historical claims
- Verify scientific terminology
- Confirm names, dates, and locations
- Flag uncertain information

The Quality Agent should validate high-risk content before publication.

---

# 21. Quality Checklist

Every generated artifact should be evaluated for:

- Accuracy
- Completeness
- Clarity
- Grammar
- Consistency
- Brand alignment
- Visual quality
- Educational value

Outputs that fail review should be regenerated or revised.

---

# 22. Continuous Improvement

The generation rules should evolve through:

- Episode reviews
- Viewer feedback
- Model improvements
- Workflow optimization
- New production standards

Changes should be documented and version controlled.

# 24. Summary

Every AI system within Mahy Mythic Labs must operate according to these generation rules. Whether producing research, scripts, images, narration, video, or metadata, the objective is always the same: deliver accurate, engaging, cinematic, and educational content that reflects the Mahy Mythic Labs brand. These rules ensure consistency across providers, models, and workflows while maintaining a high standard of quality and trust.
