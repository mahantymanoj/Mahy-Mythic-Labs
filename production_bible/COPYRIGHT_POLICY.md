# Copyright Policy — Mahy Mythic Labs

## 1. Purpose

Defines rules for legally safe content creation.

The objective is to ensure all videos respect:

* Copyright laws
* Creator rights
* Cultural ownership
* Intellectual property

---

# 2. Original Content Principle

Mahy Mythic Labs aims to create original:

* Scripts
* Narratives
* Visual concepts
* AI-generated assets
* Editing styles

---

# 3. External Assets

Before using external assets verify:

* License
* Permission
* Usage rights
* Attribution requirements

---

# 4. Music Policy

Only use:

* Licensed music
* Royalty-free music
* Original compositions
* Properly permitted audio

Never use copyrighted music without permission.

---

# 5. Image Policy

Images must be:

* Original creations
* AI-generated
* Properly licensed

Avoid:

* Unauthorized artwork
* Copyrighted characters
* Protected media assets

---

# 6. AI Content Policy

AI-generated content must:

* Follow platform rules
* Avoid impersonation
* Avoid misleading viewers

---

# 7. Cultural Respect Policy

When covering mythology or history:

Always:

✓ Respect cultural beliefs
✓ Provide context
✓ Avoid mockery

---

# 8. Fact Accuracy

Do not present:

* Speculation as fact
* Fiction as history
* Unverified claims

Clearly separate:

```text
Historical Evidence

Scientific Understanding

Cultural Interpretation
```

---

# 9. YouTube Compliance

All content must follow:

* YouTube Community Guidelines
* Copyright rules
* Monetization policies

---

# 10. Asset Documentation

Every external asset should record:

* Source
* License
* Date
* Usage purpose
