# Citation Guidelines

## Purpose

Defines citation standards for Mahy Mythic Labs content.

Goals:

* Maintain credibility
* Avoid misinformation
* Respect intellectual property
* Provide transparent sources

---

# Citation Principles

Every factual claim should be:

* Traceable
* Verifiable
* Supported by reliable sources

---

# Source Priority

Use:

```
Academic Papers

↓

Scientific Organizations

↓

Books

↓

Educational Websites

↓

General Articles
```

---

# Scientific Claims

Example:

Incorrect:

"Scientists proved aliens exist."

Correct:

"Scientists continue searching for evidence of life beyond Earth."

---

# Historical Claims

Include:

* Time period
* Location
* Civilization
* Evidence source

Example:

"Archaeological evidence from the Indus Valley Civilization suggests advanced urban planning."

---

# Mythology Content

Clearly separate:

## Traditional Belief

Example:

"In Hindu traditions, Shiva is described as..."

## Historical Study

Example:

"Historians study these texts as cultural records."

## Scientific Evidence

Example:

"No scientific evidence currently confirms supernatural events."

---

# AI Generated Content Rules

AI output must be reviewed for:

* Accuracy
* Bias
* Cultural sensitivity
* False information

---

# Video Description Citations

Recommended format:

```
Sources:

1. Book Name - Author
2. Research Paper Title
3. Organization Website
```

---

# Asset Attribution

For external assets record:

* Creator
* License
* Source
* Usage rights

---

# Copyright Rules

Never use:

* Copyrighted footage without permission
* Unlicensed music
* Protected artwork

Prefer:

* Original AI generated assets
* Licensed assets
* Public domain resources

---

# Quality Agent Checklist

Before publishing:

□ Sources reviewed

□ Claims verified

□ Copyright checked

□ Cultural sensitivity checked

□ References added
