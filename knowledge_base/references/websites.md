# Wikipedia — Special Status

Website: https://www.wikipedia.org

**How to use Wikipedia correctly:**

Wikipedia is NOT a citable primary source for Mahy Mythic Labs scripts.

However it is extremely useful as a navigation tool:

* Use Wikipedia to quickly understand a topic before deeper research
* Use Wikipedia's **References section** to find the actual academic sources
* Wikipedia footnotes often link directly to peer-reviewed papers and authoritative books

Always follow citations back to their original source before using any specific claim.

---

# Website Evaluation Checklist

Before using information from any website, verify:

- [ ] Author and credentials are clearly identified
- [ ] The organization or institution has recognized authority on the topic
- [ ] Sources or references are provided for claims
- [ ] Publication or last updated date is visible
- [ ] Claims can be cross-verified with at least one other independent source

---

# AI Agent Rules

**Never use as primary evidence:**

* Anonymous articles
* Social media posts, including Twitter/X, Instagram, or Reddit
* Personal blogs without academic credentials
* Clickbait or sensationalist websites
* AI-generated text summaries from unknown sources
* YouTube video descriptions or video content

**Social media and trending content** may only be used for:

* Understanding audience interest and trending questions
* Identifying topics that need clear factual coverage
* Discovering the kind of misconceptions the episode should address

They are never sources of factual information.
