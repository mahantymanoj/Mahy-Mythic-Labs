# What is History?

History is the study of past human events using:

* Written records
* Archaeological evidence
* Artifacts
* Oral traditions
* Scientific analysis

# Historical Research Rules

All content must:

* Separate evidence from speculation
* Mention uncertainty
* Use reliable sources
* Avoid historical misinformation

---

# Storytelling Framework

Historical narratives should include:

## Context

Where and when did it happen?

## People

Who influenced events?

## Conflict

What challenges occurred?

## Impact

How did it change humanity?
