Build a professional AI-first YouTube production studio capable of creating high-quality, cinematic, fact-based videos for the **Mahy Mythic Labs** YouTube channel.

This repository serves as the complete operating system for planning, researching, writing, producing, and publishing AI-generated videos.

# 📝 Notes

This project follows one core philosophy:

> **Think like a Creator. Work like an Engineer.**

The objective is not to automate creativity but to build a structured, repeatable workflow for producing high-quality AI-generated YouTube videos.

Every completed video should improve this repository through better documentation, refined templates, and updated production standards.
